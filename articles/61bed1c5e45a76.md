# border-shape とは？

というわけで、早速公式の仕様から見ていきたいと思います！

https://www.w3.org/TR/css-borders-4/#border-shape-func

簡単に説明すると、border-shape は 要素の輪郭の形を CSS で自由に指定できるプロパティです。輪郭に合わせて 背景・border・box-shadowも全部その形に沿って描画されるので、今までは `filter: drop-shadow()` でゴニョゴニョしないと無理だった形まわりの装飾が、宣言的にすっきり書けるようになります！

値として指定できるのは、初期値の `none` か、`<basic-shape>` 関数です。また、`<basic-shape>` の後ろに `<geometry-box>` を続けて書くこともでき、そうすることで形を描く座標が、要素のどのボックス（`content-box` / `border-box` など）を参照ボックスとして使用するかを指定できます。実際に使うときはこんなイメージになります。

```css
/* <basic-shape> のみで指定する場合 */
.card {
  border-shape: circle();
}

/* <basic-shape> + <geometry-box> で指定する場合 */
.coupon {
  border-shape: inset(0 round 16px) content-box;
}
```

`<basic-shape>` 関数や `<geometry-box>` については clip-path の MDN が分かりやすいので以下を見ていただければと思います。

https://developer.mozilla.org/ja/docs/Web/CSS/Reference/Properties/clip-path#clip-source

# clip-path / corner-shape との違い

さて、ここまでの話を聞いて「それって `clip-path` や `corner-shape` でもできるのでは？」と思った方もいると思います。

結論から言うと、border-shape の強みは 「形の柔軟性」と「影の追従」を両立できるところにあります。分かりやすいように3つの方法を並べてみました。

![clip-path / corner-shape / border-shape の比較サンプル](/images/border-shape/01-comparison.png)

:::details 実装コード

```html:comparison.html
<div class="comparison">
  <button class="btn btn-clip">clip-path</button>
  <button class="btn btn-corner">corner-shape</button>
  <button class="btn btn-shape">border-shape</button>
</div>
```

```css:comparison.css
/* 共通スタイル: 3 つのボタンに同じ青背景・同じ box-shadow を当てる */
.btn {
  --aw: 18px; /* 矢羽の突き出し量 */
  width: 160px;
  height: 64px;
  border: 0;
  color: white;
  font-size: 13px;
  font-weight: 700;
  background: #4763ff;
  box-shadow: 0 14px 0 0 rgb(15 23 42 / 0.35);
}

/* clip-path: 描画されたピクセルを 6 頂点の polygon でクリップする */
.btn-clip {
  /* clip-pathの仕様上、box-shadowは表示されなくなる */
  clip-path: polygon(
    0 0,
    calc(100% - var(--aw)) 0,
    100% 50%,
    calc(100% - var(--aw)) 100%,
    0 100%,
    var(--aw) 50%
  );
}

/* corner-shape: 角の形だけ scoop に変える（中央に頂点を作るような任意形状は不可） */
.btn-corner {
  border-radius: 32px;
  corner-shape: scoop;
}

/* border-shape: shape() で輪郭のパスそのものを定義する */
.btn-shape {
  border-shape: shape(
    from 0 0,
    hline to calc(100% - var(--aw)),
    line to 100% 50%,
    line to calc(100% - var(--aw)) 100%,
    hline to 0,
    line to var(--aw) 50%,
    close
  );
}
```

:::

それぞれ見ていくと、

- **`clip-path`**: 任意形状は作れますが、`box-shadow` も一緒にクリップされてしまいます
- **`corner-shape`**: 影はちゃんと形に追従しますが、角の形しか変えられないので矢羽のような凝った形は作れません
- **`border-shape`**: 任意形状を作れて、なおかつ影が形に追従します

特に「影が形に追従する」というのが嬉しいポイントで、例えば以下のように吹き出しの形にしても、矢印の部分にちゃんと影が落ちます。

![border-shape で作った吹き出し（矢印の部分にも影が追従している）](/images/border-shape/05-speech-bubble.png)

これ、これまでは `clip-path` + `filter: drop-shadow()` で頑張って近づける感じだったので、このように簡単に実装できるのは嬉しいです！

# 実用パターン集

## 1. 六角形

![六角形の border-shape サンプル](/images/border-shape/02-hexagon.png)

:::details 実装コード全体

```html:hexagon.html

```

```css:hexagon.css
.hexagon {
  width: 220px;
  height: 190px;
  display: grid;
  place-items: center;
  color: white;
  font-weight: 600;
  font-size: 18px;
  background: #ff5e62;
  box-shadow: 0 16px 30px -12px rgb(255 94 98 / 0.5);
  border-shape: shape(
    from 25% 0%,
    line to 75% 0%,
    line to 100% 50%,
    line to 75% 100%,
    line to 25% 100%,
    line to 0% 50%,
    close
  );
}
```

:::

ちょっとスタイリッシュな UI にしたいとき、六角形を使った UI は意外と出番が多かったりします。これまでは `clip-path` で形を切り抜いて、影は別途 `filter: drop-shadow()` で当てる、みたいな実装になりがちでしたが、以下のように `border-shape` に `shape()` を使えば 1 つの要素で完結させられます！

```css:hexagon.css
.hexagon {
  /* 省略 */
  border-shape: shape(
    from 25% 0%,
    line to 75% 0%,
    line to 100% 50%,
    line to 75% 100%,
    line to 25% 100%,
    line to 0% 50%,
    close
  );
}
```

shape 関数の使い方は以下が参考になります

https://developer.mozilla.org/ja/docs/Web/CSS/Reference/Values/basic-shape/shape

## 5. 吹き出し

![影が矢印に追従する吹き出し](/images/border-shape/05-speech-bubble.png)

:::details 実装コード全体

```html:speech-bubble.html
<div class="bubble">
  <p class="bubble-text">CSSってすごいよね！</p>
</div>
```

```css:speech-bubble.css
.bubble {
  --r: 16px; /* 角丸の半径 */
  --ah: 14px; /* 矢印の高さ（縦方向の出っ張り） */
  --aw: 14px; /* 矢印の半幅 */
  --ap: 50%; /* 矢印の x 位置（左端からの割合） */

  width: max-content;
  max-width: 320px;
  padding: 18px 20px calc(18px + var(--ah));
  background: #2a2f3a;
  color: #f7f8fa;
  box-shadow: 0 12px 28px -10px rgb(0 0 0 / 0.45);

  border-shape: shape(
    from var(--r) 0,                                /* 上辺・左角丸の終点 */
    hline to calc(100% - var(--r)),                 /* 上辺 */
    curve to 100% var(--r) with 100% 0,             /* 右上角 */
    vline to calc(100% - var(--ah) - var(--r)),     /* 右辺 */
    curve to calc(100% - var(--r)) calc(100% - var(--ah))
      with 100% calc(100% - var(--ah)),             /* 右下角 */
    hline to calc(var(--ap) + var(--aw)),           /* 下辺・矢印根元の右半分 */
    line to var(--ap) 100%,                         /* 矢印の先端へ */
    line to calc(var(--ap) - var(--aw)) calc(100% - var(--ah)), /* 矢印先端から根元の左半分へ */
    hline to var(--r),                              /* 下辺・矢印根元から左下角丸の手前 */
    curve to 0 calc(100% - var(--ah) - var(--r))
      with 0 calc(100% - var(--ah)),                /* 左下角 */
    vline to var(--r),                              /* 左辺 */
    curve to var(--r) 0 with 0 0                    /* 左上角 */
  );
}

.bubble-text {
  font-size: 15px;
  line-height: 1.6;
  margin: 0;
}
```

:::

前のセクションでも見ましたが、吹き出しの矢印部分まで `shape()` の中で記述してしまえば影もそれをなぞってくれます。

```css:speechBubble.css
.bubble {
  --r: 16px;   /* 角丸の半径 */
  --ah: 14px;  /* 矢印の高さ */
  --aw: 14px;  /* 矢印の半幅 */
  --ap: 50%;   /* 矢印の x 位置 */

  background: #2a2f3a;
  color: #f7f8fa;
  box-shadow: 0 12px 28px -10px rgb(0 0 0 / 0.45);
  border-shape: shape(
    from var(--r) 0,
    hline to calc(100% - var(--r)),
    curve to 100% var(--r) with 100% 0,
    vline to calc(100% - var(--ah) - var(--r)),
    curve to calc(100% - var(--r)) calc(100% - var(--ah))
      with 100% calc(100% - var(--ah)),
    hline to calc(var(--ap) + var(--aw)),
    line to var(--ap) 100%,
    line to calc(var(--ap) - var(--aw)) calc(100% - var(--ah)),
    hline to var(--r),
    curve to 0 calc(100% - var(--ah) - var(--r))
      with 0 calc(100% - var(--ah)),
    vline to var(--r),
    curve to var(--r) 0 with 0 0
  );
}
```

注目する点は、矢印部分も `line to` で `shape()` の中に組み込んでいるところです。これによって影が矢印の三角部分まで含めた輪郭にちゃんと落ちます。`filter: drop-shadow()` のような回避策が要らないのが良き点です！

こんな感じのイカしたパンくずリストを作成することもできます。また、パンくずリストは「クリッカブルなリンクが並ぶ」というインタラクティブ UI なので、`:hover` や `:focus-visible` といった **状態に応じた装飾** や、矢羽同士の **間隔の調整** まで考えると、形を作る手法選びがけっこう効いてきたりします。

ここでは、これまでよく使われてきた `::after` を使った実装と、`border-shape` を使った新しい実装を並べて比較してみたいと思います！

### `::after` 擬似要素 + 三角形 border を使った実装

矢羽型のパンくずは、これまで「矩形のチップの右側に `::after` 擬似要素で三角形を貼り付ける」というやり方が定番だったかと思います。

```css:crumb.css
.crumbs {
  display: flex;
}

.crumb {
  display: inline-block;
  padding: 10px 22px 10px 28px;
  background: #cbd5e1;
  margin-right: 14px; /* 三角形の幅ぶん右に空ける */
  position: relative;
}

/* 右の矢羽先端を三角形で外に張り出させる */
.crumb::after {
  content: '';
  position: absolute;
  right: -14px;
  top: 0;
  border: 21px solid transparent;
  border-left-color: #cbd5e1;
}

/* 左の V 字凹み（背景色と同じ三角を被せて切り欠きに見せる） */
.crumb:not(:first-child)::before {
  content: '';
  position: absolute;
  left: 0;
  top: 0;
  border: 21px solid transparent;
  border-left-color: white;
}
```

見た目は再現できますが、この実装にはいくつか厄介な制約があります。

- 矢羽の三角部分が要素の bounding box の外にはみ出している（`right: -14px`）ため、`gap` で間隔調整しようとしても三角形が次のチップに食い込んでしまいます。間隔を変えるには `margin-right` と三角形の幅を連動して調整する必要があり、操作レイヤーが分散します
- ホバー時に影を落としたいと思っても、擬似要素を含めた「見かけの矢羽形」に追従する `box-shadow` を作るのが難しい
- `:focus-visible` の outline は親要素の長方形にしか追従しないため、accessibility 的に整った形に沿った focus ring が出せない
- 矢羽の鋭さを変えたい（`--aw` を 14px → 20px に、など）と思ったら、三角の `border` 値・`margin-right`・padding を全部書き直し
- アクティブステップの色を変えるときも、親要素と `::after` 擬似要素の色を同期させる必要があります（プロパティが `background` / `border-left-color` と分かれているので書き分けも必要）

つまり、形の表現と layout が密結合していて、デザイン調整のコストが高めだったりします。

### border-shape での実装

`border-shape` を使うと、矢羽の形を要素の輪郭そのものとして宣言できるので、上記の制約がほとんど解消されます！

```css:chevron.css
.crumbs {
  display: flex;
  gap: 4px; /* これだけで間隔調整が完結する */
}

.step {
  --aw: 14px; /* 矢羽の突き出し量 */
  padding: 10px 22px 10px 28px;
  background: #cbd5e1;
  border-shape: shape(
    from 0 0,
    hline to calc(100% - var(--aw)),
    line to 100% 50%,                    /* 右の頂点（先端） */
    line to calc(100% - var(--aw)) 100%,
    hline to 0,
    line to var(--aw) 50%,               /* 左辺の凹み */
    close
  );
}

/* 先頭のステップだけは左辺をまっすぐにする */
.step:first-child {
  padding-left: 18px;
  border-shape: shape(
    from 0 0,
    hline to calc(100% - var(--aw)),
    line to 100% 50%,
    line to calc(100% - var(--aw)) 100%,
    hline to 0,
    close
  );
}
```

ポイントを整理すると以下の通りです。

- 矢羽の形が bounding box の中に完全に収まっているので、間隔は `gap` ひとつで完結します。三角形の幅と margin を連動させる必要はありません
- 形のパラメータ（`--aw`）と間隔（`gap`）が分離されているので、それぞれを独立して調整できます
- 影が形に追従するので、ホバー時に `box-shadow` を当てるだけで「矢羽形に浮き上がる」立体表現が手に入ります
- `:focus-visible` も明示指定（`outline: 2px solid currentColor` など）すれば形に沿うので、accessibility 要件にも応えやすい
- アクティブステップ は親要素の background を切り替えるだけ。擬似要素を意識する必要はありません

特に 「単一要素で完結する」という性質が、コードベース全体の保守性に大きく効いてきたりします。`::after` 方式だと「擬似要素の存在を意識しながらホバーやフォーカスを書く」必要があって、ちょっとした追加スタイルでバグが入りやすい一方で、 `border-shape` なら、普通の `<a>` 要素を扱っている感覚でリンクの装飾ロジックがそのまま使えるので、書いてて気持ちがいいです。

```css:scalloped.css
.card {
  width: 360px;
  height: 200px;
  padding: 32px 36px;
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  gap: 6px;
  text-align: center;
  background: linear-gradient(135deg, #ff8e53 0%, #ff3d6a 100%);
  color: white;
  box-shadow: 0 18px 32px -10px rgb(255 61 106 / 0.5);

  /* arc by <dx> <dy> of <rx> <ry> <small|large> <cw|ccw>
       dx, dy: 終点までの相対移動量
       rx, ry: 楕円の半径
```

なにか要素を目立たせたいときに使えそうな波々のエッジです。`shape()` の `arc by` を使うと、相対移動量と楕円の半径から弧を描けます。

```css:scalloped.css
.card {
  width: 360px;
  height: 200px;
  padding: 32px 36px;
  background: linear-gradient(135deg, #ff8e53 0%, #ff3d6a 100%);
  border-shape: shape(
    from 0% 0%,
    /* 上辺: 5 つの弧で右に進む */
    arc by 20% 0% of 10% 10% small cw,
    arc by 20% 0% of 10% 10% small cw,
    arc by 20% 0% of 10% 10% small cw,
    arc by 20% 0% of 10% 10% small cw,
    arc by 20% 0% of 10% 10% small cw,
    /* 右辺: 4 つの弧で下に進む */
    arc by 0% 25% of 12% 12% small cw,
    arc by 0% 25% of 12% 12% small cw,
    arc by 0% 25% of 12% 12% small cw,
    arc by 0% 25% of 12% 12% small cw,
    /* 下辺: 5 つの弧で左に戻る */
    arc by -20% 0% of 10% 10% small cw,
    arc by -20% 0% of 10% 10% small cw,
    arc by -20% 0% of 10% 10% small cw,
    arc by -20% 0% of 10% 10% small cw,
    arc by -20% 0% of 10% 10% small cw,
    /* 左辺: 4 つの弧で上に戻る */
    arc by 0% -25% of 12% 12% small cw,
    arc by 0% -25% of 12% 12% small cw,
    arc by 0% -25% of 12% 12% small cw,
    arc by 0% -25% of 12% 12% small cw,
    close
  ) content-box;
}
```

`arc by <dx> <dy> of <rx> <ry> <small|large> <cw|ccw>` という構文で、終点までの相対移動量と楕円の半径、弧の向きを指定します。最後の `content-box` は `shape()` の座標系を content-box 基準にする指定で、これがあると外側に膨らむ弧が `padding` の中に綺麗に収まり、背景もちゃんと弧の内側まで塗られます。

# Tips

さて、実用的な実装サンプルを見てきましたが、ここで今回の記事を作成するにあたって色々実装してたときにハマった点について共有したいと思います。

それは、**ブラウザ既定の focus ring（`outline-style: auto`）は `border-shape` を無視して長方形のまま描画される** というものです。

![outline: auto と outline: 2px solid の比較](/images/border-shape/focus-ring.gif)

:::details 実装コード全体

```html:focus.html
<div class="row">
  <a href="#" class="chip">outline: auto（既定）</a>
  <a href="#" class="chip explicit">outline: 2px solid</a>
</div>
```

```css:focus.css
.row {
  display: flex;
  gap: 28px;
  align-items: center;
  justify-content: center;
}

.chip {
  --arrow-size: 12px;
  width: max-content;
  padding: 12px 28px;
  background: #1f2433;
  color: white;
  text-decoration: none;
  /* 実 border を引いて border-shape の path を見えるようにする */
  border: 1px solid #4b5363;
  font: 600 13px ui-sans-serif, system-ui;
  cursor: pointer;

  border-shape: shape(
    from top left,
    hline to calc(100% - var(--arrow-size)),
    line to right center,                           /* 右の矢印先端 */
    line to calc(100% - var(--arrow-size)) bottom,
    hline to left,
    line to var(--arrow-size) center,               /* 左の V 字凹み */
    close
  );
}

/* 1. ブラウザ既定の focus-visible（outline-style: auto）
      色だけ視認性のため上書きしているが、style は auto のまま
      → focus ring は layout box の矩形になり、border-shape を見ない */
.chip:focus-visible {
  outline-color: #ff3b00;
  outline-width: 3px;
}

/* 2. 明示的に outline: 3px solid を指定
      outline-style: auto から逸脱したこの宣言は CSS の paint pipeline を通る
      → focus ring が border-shape のパスに追従する */
.chip.explicit:focus-visible {
  outline: 3px solid #ff3b00;
  outline-offset: 0;
}
```

:::

左の `outline: auto`（ブラウザ既定）はフォーカスリングが長方形のままになっているのに対して、明示的に `outline: 2px solid` と書いた右側は、ちゃんと矢羽の形に沿って outline が描かれています。

これは、ブラウザ既定の focus ring はネイティブ実装の経路で描かれるため、`border-shape` のジオメトリ情報が反映されないことが理由のようです。`outline-style` を `solid` などに明示指定すると CSS の描画パスを通るので、形にちゃんと追従するようになる、という挙動だったりします。

なので、`border-shape` を使った UI でアクセシビリティ要件を満たしたい場合は、`:focus-visible` に明示的な `outline` を書いてあげるのが安全です。

```css:focus.css
.chip:focus-visible {
  outline: 2px solid currentColor;
  outline-offset: 2px;
}
```

:::message
この挙動は Chromium 148 / 2026年5月時点で確認したものです。今後のブラウザアップデートで既定の focus ring も追従するようになるかもしれません。
:::

# 最後に

`border-shape` を触ってみた感想としては、これまで `clip-path` + `filter: drop-shadow()` の組み合わせで頑張って実装していた部分が、たった1つのプロパティで書けるようになるのがとても快適でした！気になる方はぜひ使ってみてください！

CSS にはブラウザサポートという縛りがあるので、新しいプロパティを安心して使えるようになるまで時間はかかりますが、CSS 自体は結構な勢いで進化していて、「えっ、こんなことが CSS だけでできるようになるの！？」と驚くことも多々ですし、新しい style 指定方法で簡潔に CSS を書けるようになって楽なので、色々情報を追いかけてみると楽しいかもしれないです🥰

それでは、最後まで読んでいただきありがとうございました！👋
